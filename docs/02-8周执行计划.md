# 02 · 8 周执行计划

> 每周有明确的"完成定义（DoD）"和"本周 commit 目标"。掉队一周，后面会连本带利。

---

## W1 · 背景学习 + 环境搭建

**目标**：三件套跑通，知道 KiCad 怎么点。

- [ ] 装 Python 3.10+、KiCad 8（装完能打开示例工程 `kicad/demos/`）
- [ ] 拿到 LLM API key（课程发放 / 学校算力平台备用通道），用 curl 或 python 发一次成功请求
- [ ] clone 课程模板工程，按模板 README 跑通
- [ ] 读 KiCad 8 文档中 "Schematic File Format" 一节，知道 `.kicad_sch` 是 s-expression
- [ ] `git init` 本仓库，推上 GitHub，第一次 commit

**DoD**：`python src/pipeline.py "帮我设计一块 Arduino 最小系统板"` 能跑出 `out/` 四个文件。
**本周 commit 目标**：≥ 3 个（`chore: 初始化仓库` / `feat: 打通 mock 流水线` / `docs: 补 README 快速开始`）

---

## W2 · Agent 原理入门

**目标**：手写一个最小 Agent（LLM + 一个工具 + 一次循环），不追求功能。

- [ ] 读 Prompt 工程基础（结构化输出、few-shot、约束枚举值）
- [ ] 把 `prompts/bom.md` 改写成你自己的版本，接 `--live` 调真实模型
- [ ] 观察失败：模型编造型号/漏器件，把 case 记进 `docs/失败案例.md`
- [ ] 给输出加 JSON Schema 校验（`schemas/bom.schema.json`），校验失败就重试一次

**DoD**：一句需求能稳定产出**通过 Schema 校验**的 BOM，连续 5 次不崩。
**本周 commit 目标**：`feat: 接入真实 LLM` / `feat: BOM Schema 校验与重试` / `docs: 5 个典型失败案例`

---

## W3–W4 · 最小原型 MVP

**目标**："自然语言 → BOM + 连接表"结构化 JSON 稳定可用。这是全程第一个主战场。

- [ ] W3：引脚级连接生成（`prompts/netlist.md`），要求每条连接都是 `ref + pin → net`
- [ ] W3：加自检（`src/validate.py`）：悬空网络 / 重复引脚 / 位号不存在 / 单端连接
- [ ] W4：支持 3 种板子（Arduino 最小系统 / ESP32 采集板 / 5V 稳压电源），证明不是硬编码
- [ ] W4：交互修正雏形（`prompts/revise.md`）：改一个参数，只重生成受影响的部分

**DoD**：三种需求输入，都能产出无自检错误的 `netlist.json`；能演示"把 C1 换成 100nF 后重新生成"。
**本周 commit 目标**：每周 ≥ 4 个。**这是过程分最重要的一段，千万不要攒到最后。**

---

## W5–W6 · KiCad 集成（最硬的一段）

**目标**：JSON → 真实 `.kicad_sch`，KiCad 8 打开不报错。

第一条可行路线（推荐按顺序试）：

1. **模板法**（最稳）：准备一个手工搭好的 `.kicad_sch` 模板，程序只改写位号、值、坐标、连线。先用 `kiutils` 或 `kicad-skip` 这类库读改写，避免手拼 s-expr。
2. **直拼 s-expression**：必须把用到的符号写进文件头的 `lib_symbols`，否则打开是空框。
3. **netlist 兜底**：如果原理图实在搞不定，先产出 KiCad 格式网表 `board.net`（pcbnew 可直接导入做 PCB），并如实写进报告"这一步的技术选型与取舍"——**诚实的技术取舍比假装成功得分高**。

- [ ] W5：跑通 1 个器件（电阻）的生成 → 打开 → 看得到
- [ ] W5：扩到 MCU + 电容 + 晶振 + 连接器，全部能显示
- [ ] W6：连线（wire）与网络标签（label）自动生成
- [ ] W6：封装（footprint）赋值，避免 PCB 阶段"无封装"

**DoD**：视频能录下"输入一句话 → 生成 → KiCad 打开 → 看到完整原理图"。
**本周 commit 目标**：每周 ≥ 4 个。

---

## W7 · 迭代优化 + DRC 闭环（拿进阶分）

**目标**：Agent 自己发现错、自己改。

- [ ] 把 `src/validate.py` 升级成"检查 → 报错 → 回填 Prompt → 重生成 → 再检查"循环，最多 3 轮
- [ ] 用 `kicad-cli sch erc`（KiCad 8 自带）跑真实 ERC，解析输出
- [ ] 记录每轮错误数量下降曲线（**报告里要的就是这个数据**）
- [ ] 开始写报告、准备录屏脚本

**DoD**：给一个故意写错的需求（如"用 3.3V 供电驱动 5V 继电器"），Agent 能在 3 轮内自己纠正或明确报告冲突。
**本周 commit 目标**：`feat: DRC 闭环（最多3轮）` / `chore: 补实验数据`

## 每周 5 分钟 check-in（过程分的抓手）

```bash
python scripts/checkin.py --week 3 \
  --done "打通引脚级网表生成，3 种板子都过自检" \
  --blocker "LLM 偶尔漏掉去耦电容，正在试 few-shot" \
  --next  "接 KiCad 导出，先做电阻单器件" \
  --commit
```

会自动：① 往 `PROGRESS.md` 追加一行；② `git add -A && git commit`。加 `--push` 直接推。

**固定每周日晚上做。** 掉一周就补不回来了。
