# STORY.md · PCB 设计 Agent 课程答辩（5 分钟）

## ① 意图对齐

- **目标受众**：课程老师 + 助教，课程大作业现场答辩，5 分钟陈述 + 提问。
- **核心目标**：让评委相信"我们交的不是一块板子，而是一条被 Schema/自检/闭环治理过的 Agent 流水线"，并且每一个数字都有真实运行出处。
- **PPT 长度**：10 页（5 分钟节奏：约 30 秒/页）。
- **视觉调性**：学术严谨 / 证据驱动 / 蓝白克制 / 数据锚点。
- **内容边界**：必讲——五步流水线、模型与代码分工、DRC 闭环、实验数据、失败案例；不讲——行业背景渲染、PPT 前半段的愿景叙事；禁碰——未实测的数字（真实模型数据以"进行中"如实标注）。

## ② 骨架

- 页面总数 10，不设章节扉页（5 分钟答辩，目录后直接进入正文，目录 4 条目对应正文 4 组页面）。
- Hero 页：P1 封面、P5 DRC 闭环、P10 感谢页 —— 3/10 = 30%，互不相邻。
- rhythm：P1 peak → P2 valley → P3 peak → P4 valley → P5 peak → P6 peak → P7 valley → P8 peak → P9 valley → P10 peak。P5/P6 连续 peak（数据连环冲击，可接受）。
- 非对称版式：P2/P4 非对称双栏、P3 上大图+下方卡片、P5 左图右数、P8 上大图+下方卡片、P9 左标题+右内容 = 6/10 ≥ 40%。
- 对称版式预算：P6 巨型数字+洞察、P7 表格页 —— 恰好 2 页。
